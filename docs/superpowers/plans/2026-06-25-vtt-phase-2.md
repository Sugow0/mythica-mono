# VTT Phase 2 — Fog dynamique & Fiches en session

**Date :** 2026-06-25
**Objectif :** Implémenter la Phase 2 du VTT, incluant le fog de guerre dynamique (ligne de vue simplifiée), l'intégration des fiches de personnages dans l'interface de session, et les jets de dés 2D de base.

---

## 1. Vue d'ensemble

D'après les spécifications de design (`docs/superpowers/specs/2026-06-24-virtual-tabletop-design.md`) :
- **Fog dynamique :** Handler WS `FOG_REVEAL_AROUND` qui calcule une zone visible autour d'un token.
  - *Note :* `MapDrawing` (murs, portes) étant prévu pour la Phase 3, la ligne de vue initiale sera un cercle/polygone sans obstacle (basé sur le `radius`), préparé pour intégrer le raycasting ultérieurement.
- **Frontend Fog :** Mise à jour du `FogLayer` pour supporter ce mode dynamique.
- **Fiches en session :** Fenêtre flottante / panneau latéral permettant d'afficher et d'interagir avec la `CampaignCharacterSheet` active.
- **Dés 2D :** UI d'animation CSS/Canvas pour les dés, couplée à des raccourcis sur la fiche, générant un event `DICE_ROLL`.

---

## 2. Découpage en tâches (Tasks)

### Task 1 : Backend — Handler Fog Dynamique
- Créer/Mettre à jour le payload pour l'événement `FOG_REVEAL_AROUND` : `{ tokenId: string, radius: number }`.
- Dans `apps/mythica-gameplay/src/campaigns/sessions.ws.ts`, implémenter le handler.
- La logique calculera un polygone approchant un cercle (ou utilisera le radius) et l'ajoutera à `Session.mapState.fog.revealed`.
- Gérer le broadcast vers les clients.
- Écrire les tests associés (`bun test`).

### Task 2 : Frontend — Mise à jour FogLayer
- Modifier `apps/mythica-front/src/lib/vtt/layers/FogLayer.ts` (ou le code gérant le fog).
- Gérer l'affichage des polygones `revealed` envoyés par le serveur.
- Assurer la transition entre fog manuel et dynamique.

### Task 3 : Frontend — Fiches de personnage en session
- Créer un composant (ex: `VttCharacterSheetPanel.svelte`).
- L'afficher dans un panneau latéral ou une fenêtre flottante lors de la sélection d'un Token allié (ou contrôlé par le joueur).
- Récupérer et afficher les données de la `CampaignCharacterSheet` correspondante.

### Task 4 : Frontend — Jets de dés et Chat
- Implémenter un lanceur de dés 2D (composant UI simple avec animation CSS).
- Lier les statistiques de la fiche affichée à des jets rapides.
- Émettre l'événement `DICE_ROLL` (privé/public) via le WebSocket.
- Afficher les résultats du jet dans le panneau de Chat VTT existant (`VttChatPanel.svelte`).
